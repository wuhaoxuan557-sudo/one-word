# 个人背单词 App — 规格说明（给 Codex）

## 0. 原则

- 只有一个用户，不需要账号、登录、后端或多用户支持。
- 体验参考百词斩：一次只看一个词，先选后讲，可以快速"斩"掉熟词。
- 要能在 iPhone（Safari 添加到主屏幕）和电脑浏览器上使用。
- 简单优先：本文件没有要求的库（状态管理库、UI 组件库、后端服务）一律不要引入。
- 一次只做一个里程碑（见第 8 节）。做完后停下，总结改动，等我验收。

## 1. 技术栈

- Vite + React + TypeScript（strict 模式）
- 存储：IndexedDB，通过 Dexie 访问
- 间隔重复调度：ts-fsrs
- PWA / 离线：vite-plugin-pwa
- 测试：Vitest
- 部署：纯静态站点，发布到 GitHub Pages
- **我在中国大陆使用**：运行时不得请求任何外部资源（Google Fonts、CDN 等都不行）。字体从 `assets/fonts/` 本地引入，所有依赖打包进构建产物。PWA 首次加载后要能完全离线运行。

## 2. 词库数据

来源：ECDICT（https://github.com/skywind3000/ECDICT，MIT 许可）中的 `ecdict.csv`。

写一个构建脚本 `scripts/build_wordlist.py`：

- 读取 `ecdict.csv`，按 `tag` 字段筛选。该字段以空格分隔，取值包括 `zk gk cet4 cet6 ky ielts toefl gre`。
- 每个 tag 输出一个文件 `public/wordlists/<tag>.json`。每条记录的字段为：
  `id, word, phonetic, translation, definition, pos, collins, oxford, frq, exchange`
- `translation` 中的多条释义以 `\n` 分隔，保留这种结构。超过 3 行的只保留前 3 行，供选项使用；完整内容另存一个字段，供详情页展示。
- 完整 CSV 体积很大，不要打包进前端，只输出筛选后的 JSON。
- 自定义词表：`wordlists_src/custom/*.txt` 中每行一个单词，脚本到 ECDICT 中查释义并输出 JSON。查不到的单词打印出来，由我手动补充。

## 3. 学习流程

### 3.1 每日队列

- 先排复习（已到期的卡片，按到期时间先后），再排新词。
- 新词每日上限默认 20，复习每日上限默认 200，均可在设置中修改。
- 新词顺序：按 `frq`（词频排名）升序；`frq` 为 0 或缺失的词排在最后。
- 当前学习词表可以多选，各词表之间按 `word` 去重。

### 3.2 单词卡（核心界面）

1. **认词**
   - 大字显示单词和音标，默认自动朗读一次（可在设置中关闭）。
   - 下方给出 4 个中文释义选项，其中 1 个正确、3 个干扰项。
     - 干扰项从当前词表中抽取，要求主要词性相同、词频相近。
     - 干扰项的释义不能与正确释义相同或高度重叠（例如共享第一条释义）。
   - "斩"按钮：把该词标记为已掌握，以后不再出现。可以在"已斩"列表中撤销。
   - "不认识"按钮：直接按答错处理。
2. **反馈**
   - 选对时，该选项显示绿色。
   - 选错时，所选选项显示红色，同时高亮正确选项。
   - 记录从卡片出现到作答的用时。
3. **详情**
   - 显示完整中文释义、英文释义（`definition`）、词形变化和柯林斯星级。
     - 词形变化通过解析 `exchange` 字段得到，包括过去式、过去分词、现在分词、第三人称单数、复数、比较级、最高级等。
   - 可以点击重播发音，按"下一个"继续。
   - 快速答对时，可一键跳过详情页。

### 3.3 评分到 FSRS 的映射

| 情况 | 评分 |
|---|---|
| 选错 / 点"不认识" | Again |
| 选对，用时 > 6 秒 | Hard |
| 选对，用时 ≤ 6 秒 | Good |
| 选对，用时 ≤ 2 秒，且该词从未答错过 | Easy |

- 阈值写在一个 config 对象中，可在设置中修改。
- 本次会话内的重现由 FSRS 的 learning steps 决定：到期时间落在本次会话内的卡片重新进入队列。
- "斩"的词从调度中移除，不再生成 FSRS 记录。

## 4. 发音

- 使用 Web Speech API（`speechSynthesis`）。优先选用 en-GB 或 en-US 声音，口音可在设置中选择。
- 封装成 `speak(word)`，以便以后替换为音频文件来源。

## 5. 其他界面

- **首页**：今日待复习数、待学新词数、"开始"按钮。
- **词表**：选择当前学习的词表。
- **已斩 / 生词本**：可搜索；可以撤销"斩"，也可以手动把词加入生词本（生词本中的词优先进入新词队列）。
- **设置**：每日上限、自动发音开关、口音、评分阈值、导入/导出。
- **统计**（保持简单）：
  - 近 30 天每天的复习数和首次作答正确率；
  - 累计已学数、已斩数。
  - 不要做连续打卡、成就或徽章。

## 6. 数据与备份

- IndexedDB 中的表：
  - `cards`：每个词的 FSRS 状态，以及是否已斩、是否在生词本中；
  - `reviewLogs`：每次作答的 wordId、时间戳、评分、用时、是否正确；
  - `settings`。
- 启动时调用 `navigator.storage.persist()`，尽量避免浏览器清理本地数据。
- 设置页提供"导出 JSON"和"导入 JSON"。导入前明确提示会覆盖现有数据。
- 距上次导出超过 14 天时，在首页显示一行小提示。

## 7. 视觉设计（严格按设计稿实现）

### 7.1 设计稿

- `design/html/*.html`：8 个屏幕的静态 HTML。所有尺寸、颜色、字号、圆角都写在 inline style 里。**这是权威来源**，数值以它为准。
- `design/screens/*.png`：同样 8 个屏幕的截图（390×844 逻辑像素，2 倍图），用于对照整体观感。
- 截图和 HTML 不一致时，以 HTML 为准。
- 设计稿是静态的，不要照抄它的 HTML 结构，要用 React 组件实现同样的视觉效果。

| 文件 | 屏幕 | 说明 |

### 7.3 字体

| 用途 | 字体 | 来源 |
|---|---|---|
| 英文单词、英文释义、词形、大数字 | Newsreader 400 / 500，词性用 400 italic | `assets/fonts/newsreader-*.woff2` |
| 音标 | Noto Sans 400（latin + latin-ext，覆盖 IPA 符号） | `assets/fonts/noto-sans-*.woff2` |
| 中文界面文字 | 系统字体栈：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif` | 不打包中文字体 |
| "斩"印 | `ZhanSeal`（Noto Serif SC Black 的子集，只含"斩"一个字，约 1 KB） | `assets/fonts/zhan-seal.woff2` |

字体都是 SIL Open Font License。把 `assets/fonts/` 复制到 `public/fonts/` 或 `src/assets/fonts/`，用 `@font-face` 引入。

### 7.4 尺寸与形状

- 认词页单词 52px，详情页单词 44px；首页大数字 76px；正文 15–16px；辅助文字 12–13px。
- 选项按钮：最小高度 64px，圆角 14px，描边 1.5px。主按钮：高度 56–60px，圆角 16px。卡片圆角 14px。
- 所有可点击区域不小于 44×44px。
- 斩印：44×44px，圆角 6px，`rotate(-4deg)`，字号 22px。
- 设计稿顶部和底部的留白（52–60px / 26–30px）是按 iPhone 安全区估的。实现时改用 `env(safe-area-inset-top)` 和 `env(safe-area-inset-bottom)`，并在 `index.html` 中设置 `viewport-fit=cover`。
- 电脑上内容区最大宽度 480px，水平居中，两侧显示 `--bg`。

### 7.5 交互细节（设计稿里画不出来的部分）

- **作答后的底部区域**：
  - 评分为 Good 或 Easy 时，主按钮是"下一个"（直接跳过详情页），旁边放一个文字按钮"看详情"；
  - 评分为 Again 或 Hard 时，主按钮是"看详情"。
  - 主按钮上方一行左侧显示结果（"答对了 · 1.8 秒" / "选错了"），右侧显示"评分 · 下次复习时间"（如"Good · 3 天后"）。
- 设计稿里的"重选"按钮只是原型演示用的，**不要实现**。
- **斩**：点击后弹出底部提示条"已斩 · 撤销"，3 秒后消失，期间可以撤销；然后直接进入下一张卡。
- **首页"约 N 分钟"**：用历史记录中新词和复习的平均用时来估算；没有历史时，复习按每张 8 秒、新词按每张 25 秒计算。
- **首页备份提示**：只有超过 14 天未备份时才显示。
- **动画**：只有选项变色时用 120ms 的过渡，其他地方不要弹跳、缩放或页面切换动画。
- **电脑端快捷键**：
  - `1`–`4`：选择选项
  - 空格 / 回车：下一个
  - `X`：斩
  - `R`：重播发音
  - `0`：不认识

## 8. 里程碑

| 里程碑 | 内容 |
|---|---|
| **M1** | 词表构建脚本；tokens.css 和字体；用一个词表跑通单词卡完整流程（认词 → 反馈 → 详情），这三屏按设计稿实现。数据只放内存，不持久化。 |
| **M2** | Dexie 持久化；ts-fsrs 调度；每日队列。附单元测试，覆盖评分映射、队列构建、干扰项生成和 exchange 解析。 |
| **M3** | 已斩 / 生词本、设置页、导入导出、统计页。 |
| **M4** | PWA 离线支持；部署到 GitHub Pages（附 GitHub Actions workflow）。 |
| **M5**（可选） | 拼写模式：显示中文和发音，输入单词。 |

## 9. 工程要求

- 核心逻辑写成纯函数，放在 `src/core/`，与 UI 分离。核心逻辑包括调度映射、队列构建、干扰项生成和 exchange 解析。
- `src/core/` 中的函数都要有 Vitest 测试。
- 不要用 `any` 糊弄类型。
- README 写清楚以下步骤：
  1. 下载 ECDICT 并构建词表；
  2. 在本地运行；
  3. 部署；
  4. 在 iPhone 上添加到主屏幕。
